Port Scanner

With the Port Scanner you can scan for open TCP ports on one or multiple hosts to determine which services are running.

info

TCP (Transmission Control Protocol) is a connection-oriented transport-layer protocol. Establishing a connection requires a three-way handshake between client and server. Port scanning tests whether this handshake can be initiated on a given port, which indicates a listening service.

Example inputs​

HostDescription
10.0.0.1Single IP address (10.0.0.1)
10.0.0.100 - 10.0.0.199All IP addresses in a given range (10.0.0.100, 10.0.0.101, ..., 10.0.0.199)
10.0.0.100-199All IP addresses in a given range, shorthand for the last octet (10.0.0.100, ..., 10.0.0.199)
10.0.0.0/23All IP addresses in a subnet (10.0.0.0, ..., 10.0.1.255)
10.0.0.0/255.255.254.0All IP addresses in a subnet (10.0.0.0, ..., 10.0.1.255)
10.0.[0-9,20].[1-2]Multiple IP addresses like (10.0.0.1, 10.0.0.2, 10.0.1.1, ...,10.0.9.2, 10.0.20.1)
borntoberoot.netSingle IP address resolved from a host (10.0.0.1)
borntoberoot.net/24All IP addresses in a subnet resolved from a host (10.0.0.0, ..., 10.0.0.255)
borntoberoot.net/255.255.255.0All IP addresses in a subnet resolved from a host (10.0.0.0, ..., 10.0.0.255)
PortDescription
1-1024All ports in a given range (1, 2, ..., 1024)
80; 443; 8080; 8443Multiple ports like (80, 443, 8080, 8443)
Webserver; 8080Ports of a port profile (80, 443) and other ports (8080)
note

Multiple inputs can be combined with a semicolon (;). A column pasted from Excel (one entry per line) is converted to the semicolon-separated form automatically.

Example: 10.0.0.0/24; 10.0.[10-20].1; 10.0.0.100-199 or 1-1024; 8080; 8443

IP addresses and ports that are part of multiple inputs (e.g. 10.0.0.1; 10.0.0.0/24 or 80; 1-100) are scanned only once, also an IP address entered with different hostnames (e.g. two names of one server). The hostname is resolved via DNS (PTR), not taken from the input.

A scan of more than 65,536 ports (hosts × ports, e.g. 64 hosts with 1-1024) must be confirmed, more than 16,777,216 ports cannot be scanned at once.

Ports​

The Ports input lists the recently scanned ports (history) and the port profiles (name, with the ports below). Select an entry, or type ports, port ranges and names of port profiles separated by ; (e.g. Webserver; Database; 8080). Port profiles are replaced by their ports when the scan starts. Tab completes the name of a port profile that is being typed (e.g. webserver; dat → webserver; Database), Tab again shows the next matching port profile.

Result​

The results are grouped by host (one group per IP address, the header shows the hostname, the IP address and the number of open ports) and sorted by IP address and port. The number of open, closed and timed out ports is shown next to the Result header. A port is open if the connection was established, closed if the host refused the connection and timed out if there was no answer within the timeout (e.g. blocked by a firewall). Only open ports are shown, unless Show closed ports is enabled (closed and timed out ports). The Hostname column is shown if Resolve hostname was enabled when the scan was started.

The search box right of the Result header filters the results by IP address, hostname, port, protocol, service, description and status, also while the scan is running. Export... > all exports the filtered results; the counters always count all ports.

Profile​

Inherit host from general​

Inherit the host from the general settings.

Type: Boolean

Default: Enabled

note

If this option is enabled, the Host is overwritten by the host from the general settings and the Host is disabled.

Host​

Hostname or IP range to scan for open ports.

Type: String

Default: Empty

Example:

  • server-01.borntoberoot.net
  • 1.1.1.1; 1.0.0.1
  • 10.0.0.0/24
note

See also the Port Scanner example inputs for more information about the supported host formats.

Ports​

TCP ports to scan each host for: ports, port ranges and names of port profiles (selectable in the list). Only used if the checkbox is enabled (then the ports are required), otherwise the ports of the group are used (if set there).

Type: String

Default: Empty

Example:

  • 1-1024
  • 80; 443; 8080; 8443
  • Webserver; Database; 8080
note

A port profile is referenced by the profile, so changes to the port profile apply to the profile, also if it is renamed. Its ports are saved with the profile as well: if the port profile can't be found (it was deleted, or the profile file is shared from another computer - port profiles are saved in the settings of each computer), the saved ports are used and a note is shown.

note

See also the Port Scanner example inputs for more information about the supported port formats.

Group​

Ports​

TCP ports to scan for the profiles of the group that don't set their own ports (required if the checkbox is enabled), like the ports of a profile: ports, port ranges and names of port profiles. If neither the profile nor the group has ports, the ports input is empty and the scan is not started.

Type: String

Default: Empty

Example:

  • 22; 3389; 5985
  • Webserver; 8080

Settings​

Port profiles​

List of common TCP ports to scan for. A port profile can be entered by its name in the ports input (case-insensitive, also several and together with ports, e.g. Webserver; Database; 8080), so the name must be unique, must not contain ; and must not be a port or port range (e.g. 80). Several port profiles can be selected and deleted at once (context menu or Del).

Type: List<NETworkManager.Models.Network.PortProfileInfo>

You can also use the Hotkeys F2 (edit) or Del (delete) on a selected port profile, or double-click it to edit it.

Show closed ports​

Show closed and timed out ports in the result list.

Type: Boolean

Default: Disabled

Timeout (ms)​

Timeout in milliseconds after which a port is considered timed out (no answer). A port is closed if the host refused the connection.

Type: Integer [Min 100, Max 15000]

Default: 2000

note

A closed port is reported as soon as the host refuses the connection. Each attempt sends the connection request once (see Attempts).

Attempts​

Number of connection requests sent to each port. Another request is only sent if there was no answer (timed out), an open or closed port is final.

Type: Integer [Min 1, Max 10]

Default: 1

tip

In a local network (LAN), 1 is enough. On an unreliable network (e.g. Wi-Fi, VPN) or for hosts on the internet, a lost connection request can make an open port appear as timed out - increase it to 2 in this case. This only takes longer for ports without answer (attempts × timeout), e.g. ports blocked by a firewall.

Ping hosts before the scan​

Pings every host before its ports are scanned (ICMP echo, with the Attempts, Timeout and Buffer below). Only hosts that answer are scanned, the number of hosts that were not scanned is shown below the input after the scan. Faster for ranges with many unused IP addresses (e.g. a /24 with 1-1024), because the ports of unused addresses are not scanned until their timeout. With Adjust threads automatically, up to 128 hosts are pinged at the same time and a host is scanned as soon as it answers; otherwise each host is pinged when it is scanned, so Max. concurrent host threads also limits the pings.

Type: Boolean

Default: Disabled

warning

Hosts that block ICMP (e.g. Windows with the firewall enabled) are not scanned, even if they have open ports.

Attempts​

Maximum number of ICMP requests sent to each host before the scan (only with Ping hosts before the scan). Another request is only sent if the previous one has timed out (e.g. a lost packet), other replies like "destination host unreachable" are final.

Type: Integer [Min 1, Max 10]

Default: 2

Timeout (ms)​

Timeout in milliseconds for each ICMP request before the scan (only with Ping hosts before the scan), after which the packet is considered lost. A host that doesn't answer is skipped after about attempts × timeout.

Type: Integer [Min 100, Max 15000]

Default: 2000

Buffer​

Size of the buffer for each ICMP request before the scan in bytes (only with Ping hosts before the scan).

Type: Integer [Min 1, Max 65500]

Default: 32

Resolve hostname​

Resolve the hostname for given IP addresses.

Type: Boolean

Default: Enabled

Adjust threads automatically​

Adjusts the number of hosts and ports that are scanned at the same time to the scan: up to 512 connections at the same time, at most 128 hosts and 128 ports per host. For example, 1-1024 scans 4 hosts with 128 ports at the same time, a single port (e.g. 3389 on a /24) 128 hosts. Max. concurrent host threads and Max. concurrent port threads are only used if this option is disabled, e.g. to slow down a scan.

Type: Boolean

Default: Enabled

note

When updating from an older version, this option is disabled if the threads were changed, so the changed values still apply.

Max. concurrent host threads​

Maximum number of hosts that are scanned at the same time, if Adjust threads automatically is disabled. A thread is not an operating system thread, but one host whose ports are scanned concurrently.

Type: Integer [Min 1, Max 256]

Default: 4

warning

The scan opens up to host threads × Max. concurrent port threads TCP connections at the same time (with the default settings up to 4 × 128 = 512), at most 8,192 (every connection uses a local port, this is half of them) - the maximum of one setting depends on the other (e.g. 256 host threads allow 32 port threads). Too many simultaneous requests may be detected as a port scan and blocked or rate-limited by a firewall (local, on the network or on the scanned host) and can overload small routers. If ports are missing in the result (shown as timed out) or the network becomes slow during the scan, reduce the number of threads. This will increase the scan time.

Max. concurrent port threads​

Maximum number of ports that are scanned at the same time for each host, if Adjust threads automatically is disabled.

Type: Integer [Min 1, Max 512]

Default: 128

warning

Too many simultaneous requests may be detected as a port scan and blocked or rate-limited by a firewall (local, on the network or on the scanned host). If ports are missing in the result (shown as timed out), reduce the number of threads. This will increase the scan time.
