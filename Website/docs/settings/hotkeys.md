# HotKeys

### Untray / Bring to foreground

Untray the application and bring it to the foreground.

**Type:** `Boolean`

**Default:** `Disabled`

**Default Hotkey:** `Ctrl+Alt+O`

### Bring window to foreground and open the run command

Untray the application, bring it to the foreground and open the [run command](../run-command.md), so a feature can be run from anywhere (e.g. `ping 10.0.0.1`).

**Type:** `Boolean`

**Default:** `Disabled`

**Default Hotkey:** `Ctrl+Alt+P`
